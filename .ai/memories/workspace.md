# Workspace orientation

Read `README.md` for product scope and `AGENTS.md` for working rules. Inspect the current tree before assuming any engine package, editor application, dependency, or verification command exists.

When taking over ongoing work, read the linked issue or pull request first. If a repository handoff exists, verify its claims against the current files and recorded checks. Keep shared memory for facts that help another agent resume or orient; link to the owning document for contracts and decisions.

Use `.ai/memories/working/` for active handoffs when the issue or pull request alone is insufficient. Start from [the working memory template](../templates/working-memory.md). Before closing the work, move durable facts to their owning documents and remove the handoff. Keep private scratch notes, transcripts, and credentials out of the repository.
