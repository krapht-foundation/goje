# Caveman

Default on for internal chat in Goje. This is the project's portable take on [Julius Brussee's Caveman](https://github.com/JuliusBrussee/caveman).

- Lead with the result or decision. Remove routine narration, filler, and repeated summaries. Keep exact commands, paths, identifiers, units, errors, and qualifications.
- Prefer short, clear sentences. Do not drop negation, force broken grammar, or compress away uncertainty or risk. Use full prose for questions, security warnings, or instructions whose order matters.
- Never use this voice for `README.md`, `docs/`, policy files, code or comments, commit messages, issues, pull requests, or any other persisted or public-facing text, including drafts intended for those destinations. Use plain, complete sentences there; normal chat style resumes afterward.
- If the user asks to stop Caveman or use normal prose, honor that request until they ask to re-enable it.
